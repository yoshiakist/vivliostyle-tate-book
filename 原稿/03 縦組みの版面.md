<h2>第三章　縦組みの版面</h2>

<h3>縦組みの方向</h3>

CSS で縦組みを扱うとき、最初に頭を切り替えておきたいことがあります。それは「縦・横」ではなく「行の向き・行の並ぶ向き」で考える、ということです。

文字が並んで一行を作っていく向きを **インライン方向**、その行が次々に並んでいく向きを **ブロック方向** と呼びます。横書きなら、インライン方向は左から右、ブロック方向は上から下です。縦書きでは、インライン方向が上から下、ブロック方向が右から左になります。

CSS には、この二つの方向で大きさを指定する書き方があります。「行の長さ」を指定したいなら、縦組みでも横組みでもインライン方向の大きさを指定すればよく、それが画面の高さなのか幅なのかを気にしなくて済みます。この本の CSS は、できるだけこの書き方で統一しています。

<div class="page-break"></div>

<div class="caution">
<span>ここに注意</span>

「幅」と「高さ」で指定する昔ながらの書き方は、縦組みにしても入れ替わりません。幅はいつでも画面の左右の長さ、高さはいつでも上下の長さです。縦組みで行の長さを「幅」で指定してしまい、思った向きに効かない、というのはとてもよくある失敗です。
</div>

<h3>判型と単位</h3>

この本の判型は A5（148mm × 210mm）です。単行本や同人誌でよく使われる大きさです。

文字の大きさには Q（級）という単位を使っています。一級は 0.25mm で、写植の時代から和文の組版で使われてきた単位です。CSS でもそのまま使えます。本文は <span class="tcy">16</span>Q、つまり 4mm 角の文字です。ポイントで言えば、だいたい <span class="tcy">11</span> ポイント強にあたります。

mm で考えられる単位を使うと、紙の上での寸法と CSS の数値が直接つながるので、版面の計算がしやすくなります。

<h3>版面の計算</h3>

版面とは、紙のうち本文が組まれる領域のことです。和文の組版では、版面を「余白を引いた残り」として決めるのではなく、「文字の大きさ・一行の字数・行数」から積み上げて決めるのが基本です。そうすることで、行の終わりに中途半端な空きが出ず、どのページも字詰めがぴたりと揃います。

この本の版面は、次の数値から決めています。

<div class="indent-1">

文字の大きさは <span class="tcy">16</span>Q。

行送り（一行の中心から次の行の中心までの距離）は、文字の大きさの 1.75 倍。

一ページの行数は <span class="tcy">18</span> 行。

一行の字数は <span class="tcy">42</span> 字。
</div>

縦組みでは、行の長さ（インライン方向）は「文字の大きさ × 字数」、版面の幅（ブロック方向）は「文字の大きさ × 行送り × 行数」で求まります。この二つを CSS に計算式のまま書いておけば、文字の大きさを変えたときにも版面が自動で追従します。
実際には、句読点を行末にはみ出させる（ぶら下げる）ぶんの小さな余裕を、それぞれ少しだけ足しています。

<blockquote>

<span class="small_heading">この章の要点</span>

版面は余白から決めない。文字の大きさと字数と行数から積み上げる。
</blockquote>

<h3>余白とノンブル</h3>

版面の外側の余白には、それぞれ名前があります。ページの上が **天**、下が **地**、綴じる側が **ノド**、開く側が **小口** です。

縦組みの本は右綴じなので、見開きの右ページと左ページでノドと小口が入れ替わります。CSS には右ページと左ページに別々の指定をする仕組みがあり、この本ではそれを使って、左右のページで小口側の余白とノンブル（ページ番号）の位置を振り分けています。ノンブルは地の外側、小口寄りに置き、縦組みの中でも数字は横書きで組んでいます。

天の余白は固定の値で取り、左右は版面を真ん中に寄せたうえで小口側を調整しています。版面の大きさを数値から先に決めているので、余白は「その残り」として自然に決まります。

<h3>改ページ・字下げ・禁則</h3>

章の見出しは、必ず新しいページから始めています。CSS で「この見出しの前では改ページする」「この見出しの直後では改ページしない」と指定しておけば、見出しだけがページの最後に取り残されることもありません。書名を置く扉の見出しは、前後の両方で改ページして、一ページを独占させています。

段落は一字下げで始めます。ただし、会話文のように開き括弧で始まる段落は、字下げをしない（天付きにする）のが和文の習慣です。開き括弧はもともと字形の中に半分ほどの空きを持っているので、さらに一字下げると下がりすぎて見えるためです。
この本では、開き括弧で始まる段落をビルドのときに自動で見分け、字下げを外す名札を付けています。原稿の側では何も気にせず書けます。

行頭に句読点や閉じ括弧が来ないようにする決まりを、禁則処理と呼びます。CSS では、その厳しさの程度を選べます。この本では厳しめの設定にし、あわせて行末の句読点を版面の外へぶら下げる指定もしています。

<h3>書体</h3>

本文は明朝体で組んでいます。ウェブフォントとして配布されている明朝体を読み込み、手元にそれが無い環境のために、OS に入っている明朝体を順に代わりとして並べています。

引用や要点の枠は、本文と区別するためにゴシック体にしています。枠の中は文字を少し小さくし、行送りと字間を広げて、本文よりもゆったり読めるようにしています。

<div class="caution">
<span>ここに注意</span>

ウェブフォントは、ビルドのときにインターネットから読み込まれます。通信できない環境でビルドすると、代わりの書体で組まれてしまい、字詰めや改ページの位置が変わることがあります。仕上げのビルドは、書体が確実に読み込める環境で行ってください。
</div>
