<h2>第一章　本をコードで組む</h2>

<h3>vivliostyle とは</h3>

vivliostyle は、 HTML と CSS を使って、本の紙面を組むソフトウェアです。
HTML は文章の構造（ここが見出し、ここが段落、ここが引用）を表す書き方で、CSS はその見た目（文字の大きさ、余白、縦書きか横書きか）を指定する書き方です。

ふつうのウェブブラウザは、HTML と CSS を受け取って画面に表示します。vivliostyle はそれを「紙のページ」に割り付けます。ページの大きさ、余白、ページ番号の位置、どこで改ページするかといった、本に特有の決まりも CSS で書けるようになっています。こうした組み方を **CSS 組版** と呼びます。

<div class="page-break"></div>

<blockquote>

<span class="small_heading">この章の要点</span>

本の見た目を、一ページずつ手で整えるのではなく、決まりとして先に書いておく。あとはその決まりに従って、ソフトが全ページを組む。
</blockquote>

<h3>原稿が本になるまで</h3>

この本の作り方では、原稿は章ごとのテキストファイルです。書き方は Markdown（マークダウン）という簡単な記法を基本にし、必要なところだけ HTML のタグを混ぜます。

原稿が本になるまでの流れは、おおよそ次のとおりです。

<div class="indent-1">

まず、原稿のテキストファイルが HTML に変換されます。このとき、ルビの記法を本物のルビに置き換えたり、段落の中の不要な改行を詰めたりといった下ごしらえも行います。

次に、その HTML に印刷用の CSS が当てられ、vivliostyle が紙面に組みます。中ではウェブブラウザと同じ仕組みが動いているので、組み上がった紙面はブラウザでそのまま確認できます。

最後に、組み上がった紙面が PDF として書き出されます。EPUB を作るときは、同じ HTML を電子書籍の形式に詰め直し、電子書籍向けの CSS を重ねます。
</div>

この一連の作業は、コマンドを一つ打てば最初から最後まで自動で進みます。原稿を一文直したら、もう一度ビルドする（組み直す）だけです。

<h3>この作り方の利点と、向かないもの</h3>

いちばん大きな利点は、原稿がただのテキストであることです。どんなエディタでも開け、変更の履歴を Git などの道具で細かく残せます。どの日にどの文を直したかを、あとから一行単位でたどれます。

二つ目は、紙と電子が一つの原稿から出ることです。紙の版を直したのに電子版が古いまま、という食い違いが起きません。

三つ目は、見た目の決まりが一か所に集まることです。「章の見出しは必ず改ページ」「段落は一字下げ」といったルールを CSS に書いておけば、原稿の側では一切気にしなくてよくなります。決まりを変えたくなったら CSS を直すだけで、全ページに反映されます。
<br /><br />

一方で、向かない本もあります。雑誌のように、ページごとに写真と文字を自由に配置する誌面は、一枚ずつ手で動かせる DTP ソフトのほうが早いことが多いでしょう。CSS 組版が得意なのは、文章が主役で、同じ決まりが最初から最後まで続く本です。小説、エッセイ、解説書、論文などがそれにあたります。

<div class="caution">
<span>ここに注意</span>

CSS 組版は、ウェブブラウザの仕組みに乗っています。そのため、紙の組版ソフトなら当然できることが、CSS ではまだ書けない、あるいはソフトによって対応がまちまち、ということがあります。とくに電子書籍リーダは機種ごとの差が大きく、第五章で詳しく扱います。
</div>

<h3>このリポジトリの中身</h3>

この本の原稿と設定は、一つのフォルダにまとまっています。中身を言葉で一周しておきます。

<div class="indent-1">

**原稿フォルダ** には、章ごとの原稿ファイルが入っています。前付け（扉・はじめに・目次）だけは一つのファイルにまとめてあり、その仕組みは第四章で説明します。

**css フォルダ** には、紙のための CSS と、電子書籍のための上書き用 CSS の二枚が入っています。

**設定ファイル** は一つだけです。どの原稿をどの順に並べるか、書名は何か、ルビをどう変換するかといったことを、ここにまとめて書きます。

**AI 向けの指示書** も置いてあります。原稿の形式や文体の決まり、ビルドの仕組みを、AI エージェントが作業の前に読むための文書です。第六章で扱います。
</div>

</div>
