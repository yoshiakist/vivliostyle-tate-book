# 原稿の文字数カウント

原稿の**本文だけ**を対象に文字数を数える。以下を本文でないものとして除去してから、空白・改行を除いたコードポイント数を数える。

- `<!-- … -->` — HTML コメント（前付けファイル冒頭の説明など）
- `<div class="rule">…</div>` — AI 向けの執筆規約（内部メモ）
- `<div class="comment">…</div>` — 著者メモ（内部メモ）
- `<div class="page-image">…</div>` — 1ページ大の図版
- 見出し（`<h1..6>…</h1..6>` と Markdown の `#…` 行）
- ルビの読み `《…》` — 振り仮名は注記なので数えない（親字は残す）
- 残りの HTML タグ・HTML エンティティ・空白

引用ブロック（`<blockquote>`）・注意枠・問いかけ枠の中身は読者に向けた本文なので**残して数える**。

## 使い方

```bash
# 原稿/*.md をすべて集計（ファイル名順に一覧＋合計）
npm run count
# = node .claude/skills/count-manuscript/count.mjs

# ファイルを指定して集計
node .claude/skills/count-manuscript/count.mjs "原稿/01 本をコードで組む.md"

# JSON で出力（プログラム連携用）
node .claude/skills/count-manuscript/count.mjs --json
```

引数なしなら `原稿/` 直下の `.md` を名前順に走査する。

## 注意

- 規約と見出しだけの書きかけの章は 0 字になる。これは正常。
- 数えるのは概算の目安。章ごとの分量の比を見る用途に向く。
- 除去規則は原稿の HTML 形式に依存する（規約ブロックの中に入れ子の `<div>` を置かない前提で、最短一致の正規表現で除いている）。形式を変えたら [count.mjs](count.mjs) の正規表現も合わせる。
